# Figuras de procesos descritos

Cada SVG exporta el JSON de P01; el DOT conserva su fuente gráfica. Una caja es una acción y un rombo una decisión; los óvalos señalan límites de inicio/cierre. Las etiquetas incluyen rol y localizador del nodo. Las prácticas generales o agrupaciones analíticas llevan indicación explícita.

Flecha continua: secuencia, condición o intercambio conforme al tipo registrado. Línea de puntos sin dirección: solapamiento, sin imponer precedencia. Flecha discontinua azul: retorno. Relación ocre discontinua: organización analítica de representación; no hecho adicional comprobado. El detalle y la justificación están en el JSON y la explicación. Una flecha no acredita una norma institucional.

Esta exportación fue realizada por coordinación desde la copia revisada 1.1. No sustituye ni certifica el ZIP original no recibido. Las cajas de igual altura no implican simultaneidad y su disposición no añade precedencia. Los mapas representan cinco actividades distintas y no una cadena entre perfiles. Lo ideal y contrafactual se conserva fuera del recorrido principal. No hay proceso formal verificado en estas figuras. Las citas se consultan en los soportes, sin saturar las cajas.
