# Soportes N01 revisados 1.1

Referencia: datos/N01_necesidades_revisadas_v1_1.json y explicación revisada. La revisión conserva 29 enunciados, 351 evidencias, prioridades y criterios. Se separan códigos asignados en segmentos citados de seis relaciones conceptuales del análisis; ver enlaces_codigos.csv, necesidades.csv y trazabilidad.csv. Los demás CSV mantienen sus datos.

Las cinco figuras seleccionan decisiones de los cinco casos. Se reutilizan íntegramente SVG/PNG exportados para 1.0: todos sus campos visualizados coinciden con 1.1. No se afirma nueva exportación. Coordinación inspeccionó las cinco imágenes y no observó cortes o solapamientos; son soportes ampliables, no maquetación final de diez páginas. fuentes/ conserva datos y script originales de esas figuras.

Los controles originales están íntegros en soportes_recibidos del expediente maestro. Esta carpeta incluye control real revisado, script y control de compatibilidad de soportes. El script requiere como base el paquete N01_insumos_v1 original. Las huellas de entrada y lectura recibidas conservan su origen histórico; no son una nueva ejecución analítica.

No se realizó prueba de usuarios o validación humana independiente. Las verificaciones son propuestas, prioridades son locales y portafolio entre casos sigue pendiente. Licencias o permisos de difusión no se deducen de disponibilidad. La siguiente etapa construirá historias, perfiles analíticos y prototipos de objetos digitales orientados a FDO, con identificadores locales y sin conformidad integral declarada.
